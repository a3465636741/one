# 校园活动中心

面向校园学生的活动信息聚合、分类搜索与官方入口跳转平台。

## 项目目标

解决校园活动分散在社团群、公众号、朋友圈和论坛中，学生难以集中发现、比较和找到官方报名入口的问题。平台只负责收集、展示、搜索和跳转；报名、签到等流程仍在主办方原有系统中完成。

本项目同时作为可部署的软件作品完成：开发者不负责长期运营活动内容，而是提供系统、部署说明和管理后台，由交付对象自行维护内容。

## 第一版（MVP）

- 活动浏览、分类筛选、搜索与详情查看
- 活动主办方、时间、地点、活动介绍展示
- 官方报名链接或二维码展示与跳转
- 管理员审核活动
- 活动内容的收集与维护

## 技术方向

- 前端：Vue 3 + TypeScript
- 后端：Java + Spring Boot
- 数据库：MySQL
- 后续按实际需求引入 Redis、Docker 和 Nginx

## 本地运行前端

```bash
cd frontend
npm install
npm run dev
```

生产构建：

```bash
cd frontend
npm run build
```
