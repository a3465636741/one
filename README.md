# 校园活动中心

面向校园组织者的活动发布、报名、签到与通知管理平台。

## 项目目标

解决校园活动从发布、报名到现场签到和活动通知分散在多个群聊与表格中的问题，让组织者更高效地管理活动，让学生更方便地发现和参与活动。

## 第一版（MVP）

- 学生注册、登录与个人信息维护
- 活动浏览、分类筛选、搜索与详情查看
- 组织者发布活动并查看报名名单
- 学生报名和取消报名
- 管理员审核活动
- 活动开始前的定时提醒

## 技术方向

- 前端：Vue 3 + TypeScript
- 后端：Java + Spring Boot
- 数据库：MySQL
- 后续按实际需求引入 Redis、Docker 和 Nginx
