# 活动方使用说明

## 1. 本地演示登录

1. 先启动后端和前端。
2. 打开 `http://localhost:5173/organizer`。
3. 使用账号 `techclub` 和初始密码 `campus-organizer-2026` 登录。
4. 首次登录后先在“账号”页面修改密码。

演示账号绑定“启航科技社”。活动方不能选择其他主办方，也不能查看或修改其他组织的活动。

## 2. 新建和提交活动

1. 在“我的活动”点击“新建活动”。
2. 填写标题、分类、时间、地点、摘要和详情。
3. 填写信息来源地址，例如原始通知、公众号文章或组织官网。
4. 至少填写一个官方链接或二维码图片地址。
5. 保存草稿，在活动列表点击“提交审核”。

保存草稿时允许暂时缺少来源或官方入口，但提交审核时系统会检查这两项。平台只展示活动并引导学生前往第三方官方入口，不处理学生报名、签到或支付。

## 3. 审核状态

| 状态 | 含义 | 活动方可执行操作 |
| --- | --- | --- |
| 草稿 | 尚未提交 | 编辑、提交审核 |
| 待审核 | 等待管理员处理 | 取消活动 |
| 已退回 | 管理员要求修改 | 查看退回原因、编辑、重新提交 |
| 已发布 | 已展示在学生端 | 取消活动 |
| 已取消 | 活动方主动取消 | 暂无 |
| 已下架 | 管理员停止公开展示 | 联系管理员处理 |

## 4. 正式环境账号

首次部署时，可通过 `ORGANIZER_INITIAL_ID`、`ORGANIZER_INITIAL_USERNAME`、`ORGANIZER_INITIAL_PASSWORD` 和 `ORGANIZER_INITIAL_DISPLAY_NAME` 创建一个活动方账号。`ORGANIZER_INITIAL_ID` 必须对应已有的 `organizers.id`。

当前版本尚未提供管理员创建多个活动方账号的页面。交付客户需要新增更多账号时，应由部署人员在受控流程中创建；“活动方邀请与账号管理”可以作为下一阶段功能。
