# 活动信息采集表

> 目标：收集至少 10 条**公开可验证**的校园活动，作为第一版页面原型、数据库字段和演示数据的依据。
>
> 填写原则：只记录公开推文、公开网页、公开海报或主办方明确提供的信息；不要记录群聊截图中的个人联系方式、报名名单或其他个人信息。

## 字段说明

| 字段 | 填写要求 |
| --- | --- |
| 活动标题 | 保持主办方原始标题，必要时可补充简短说明 |
| 分类 | 讲座 / 比赛 / 志愿 / 文体 / 社团招新 / 学术 / 其他 |
| 开始与结束时间 | 未写明则标注“待确认” |
| 地点 | 校区、楼宇、教室或线上平台 |
| 主办方 | 学院、社团、组织或官方账号名称 |
| 简介 | 用 1～2 句话概括；不要照搬太长的推文内容 |
| 海报 | 公开图片链接、截图文件名或“无” |
| 官方入口 | 可点击链接优先；若只有二维码，写“仅二维码” |
| 来源 | 原始公开推文/网页链接，或公开海报的出处 |
| 状态 | 待整理 / 信息完整 / 已过期 / 不适合收录 |

## 采集渠道建议

1. 山西大学各学院、社团和学生组织的公开微信公众号推文。
2. 山西大学官网、学院官网和公开公告栏。
3. 社团的公开微博、抖音、小红书或公开网页。
4. 已取得主办方同意的公开活动海报和报名入口。

## 完成判断

当至少 10 条记录中有 7 条以上包含“标题、分类、时间、地点、主办方、来源”，并且至少 5 条有可用的官方链接或二维码时，即可进入第 1 周的原型设计和第 2 周的数据库设计。

## 与 Codex 的协作方式

你可以直接把公开活动链接、海报截图或文字转发给我。我会：

1. 判断是否适合收录；
2. 提取字段并补到本表；
3. 标记缺失信息和外部入口类型；
4. 在收集够 10 条后，依据真实数据设计数据库和页面。
