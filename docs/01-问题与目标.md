# 问题与目标

## 要解决的问题

校园活动通常通过微信群、QQ 群、公众号推文、朋友圈和论坛传播。信息分散且容易遗漏，学生很难按兴趣、时间或类别集中查找，也很难快速找到主办方提供的原始报名入口。

## 目标用户

- 学生：发现感兴趣的活动、查看详情、进入主办方的官方报名页面。
- 活动组织者：提交活动信息、官方链接或二维码，获得更多曝光。
- 管理员：收集、审核和维护活动内容，保证链接和二维码有效。

## 项目目标

在第一版中，完成“收集活动信息 → 分类展示与搜索 → 学生查看详情 → 跳转主办方官方入口”的核心闭环。

## 初步观察（待继续访谈验证）

一名山西大学在校学生反馈：学校存在讲座、社团和其他校园活动，但活动通知分散，学生经常不知道近期有什么活动，因此错过参与机会。

这说明第一版应优先解决“活动能否被发现”的问题，而不是替代主办方的报名和签到流程。后续还需访谈更多学生，验证信息分散的渠道、最需要的筛选条件，以及他们是否愿意使用一个统一入口。

## 不做什么

第一版不做站内报名、报名名单、站内签到、在线支付、聊天、复杂推荐算法、积分商城、微服务和多校区运营。
