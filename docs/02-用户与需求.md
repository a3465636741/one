# 用户与需求

## 学生需求

- 我希望按类别、时间和地点找到校园活动。
- 我希望快速了解活动的主办方、时间、地点和要求。
- 我希望点击链接或扫描二维码，就能进入主办方提供的官方报名页面。

## 组织者需求

- 我希望能提交活动海报、介绍、时间地点和官方报名链接/二维码。
- 我希望学生能通过搜索和分类发现我的活动。
- 我不需要在这个平台管理报名名单或现场签到。

## 管理员需求

- 我希望审核待发布活动，处理违规或重复内容。
- 我希望能管理用户和活动状态。

## 待验证问题

- 活动信息最常发布在哪里？是否可以由主办方主动提交？
- 官方报名入口通常是链接、问卷还是二维码？
- 主办方是否愿意授权平台展示海报、二维码和原始链接？
- 哪些分类、筛选条件能让学生更快找到活动？
